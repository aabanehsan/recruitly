How matching works

Google Forms names uploaded files like IMG_2041 - Jordan Lee.jpg, so files are matched by the person's name. A file is also matched if its name contains someone's email username or UT EID. If two people could match a file equally well, it's skipped so nobody gets the wrong photo.
